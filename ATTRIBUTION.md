# Artwork and technology marks

The profile layout and animation are custom SVG artwork generated by `tools/build_profile.py`. Rebuild with Python 3.12 or later: `python tools/build_profile.py`. No Python packages, JavaScript, remote fonts, or hosted image generators are required.

Technology icon paths are vendored from [Simple Icons](https://github.com/simple-icons/simple-icons), pinned to commit `cd796c98565fc466923fc1128b962e133fa3c612`. See `assets/icons/LICENSE.md` for the upstream license. Names and logos remain trademarks of their respective owners; their inclusion does not imply endorsement, employment, certification, or affiliation. Logos illustrate the disciplines in the timeline rather than exhaustively documenting a production tool stack.

Animations use CSS inside SVG image assets, with a static base composition and a reduced-motion media query. Browser and GitHub image-proxy behavior may affect animation playback; no scripts or interactive controls are embedded inside the SVGs. Links are regular README anchors around the images.

The diagrams are conceptual. They are not live metrics, GitHub statistics, or performance claims. Dates and career areas follow the account owner's supplied timeline.
