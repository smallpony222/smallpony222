# Artwork and technology marks

The white editorial layout and animation are custom SVG artwork generated by `tools/build_profile.py`. Rebuild with Python 3.12 or later: `python tools/build_profile.py`. No Python packages, JavaScript, remote fonts, or hosted image generators are required. The README and its text labels use ASCII to avoid corrupted separators or date ranges.

Technology icon paths are vendored from [Simple Icons](https://github.com/simple-icons/simple-icons). Each icon's source is pinned in `assets/icons/sources.json`; older icons use commits `3fd92a7d0656c3d780bccdf7b5a3e9b9991dd6e5` and `0af835e2949a9222965522780e5e0810d3c53382`, while current icons use `cd796c98565fc466923fc1128b962e133fa3c612`. See `assets/icons/LICENSE.md` for the upstream license. Names and logos remain trademarks of their respective owners; their inclusion does not imply endorsement, employment, certification, or affiliation. Logos illustrate the disciplines in the timeline rather than exhaustively documenting a production tool stack.

Animations use CSS inside SVG image assets, with a static base composition and a reduced-motion media query. Browser and GitHub image-proxy behavior may affect animation playback. No scripts or interactive controls are embedded inside the SVGs. Native GitHub details/summary elements make each chapter's entire logo panel an expansion control. Selecting a logo anywhere on that panel reveals the chapter's motion study; individual logos do not have separate event handlers or links. Opening a section reveals a looping animation but does not guarantee restarting its timeline. The README contains no navigation links, contact buttons, or text-journey fallback.

The diagrams are conceptual. They are not live metrics, GitHub statistics, or performance claims. Dates and career areas follow the account owner's supplied timeline.
