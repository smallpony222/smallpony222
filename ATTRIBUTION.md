# Artwork and technology marks

The layout and animation are custom SVG artwork generated by `tools/build_profile.py` from `tools/chapters.json` and `tools/workflows.json`. Rebuild with Python 3.12 or later: `python tools/build_profile.py`. No Python packages, JavaScript, remote fonts, or hosted image generators are required. The README and its text labels use ASCII to avoid corrupted separators or date ranges.

Artwork is transparent, and icon colors are normalized to a luminance range that remains visible on white and GitHub's dark canvas. Technology names and workflow labels are native GitHub text and inherit the actual site theme; chapter artwork uses the same balanced SVG palette. This avoids depending on operating-system theme detection or adding theme-marker hyperlinks.

The main visual is an animated circular overview of the five overlapping career stages, with clockwise flow, arrowheads, orbiting markers, and technology marks. The circle is an image, not a clickable image map: chapter selection happens through five native controls immediately below it. All chapter controls share the same details `name`, so browsers with named-details support keep only one open. The AI chapter (2024-2026) has `open` in the source and is selected on initial load. Browser history restoration may restore a visitor's previous accordion state.

Within each chapter, a two-column technology gallery uses consistent logo canvases, centered names and workflow labels, and an independent reveal in every tile. A final unpaired tile spans both columns with its logo kept at the same scale. Gallery sizing is checked against GitHub's actual Markdown stylesheet, including its intrinsic table sizing. Compact mobile diagrams stack nodes and route dependencies and feedback paths through side channels rather than shrinking the full desktop diagram into a narrow cell.

Technology icon paths are vendored from [Simple Icons](https://github.com/simple-icons/simple-icons). Each icon's source is pinned in `assets/icons/sources.json`; older icons use commits `3fd92a7d0656c3d780bccdf7b5a3e9b9991dd6e5` and `0af835e2949a9222965522780e5e0810d3c53382`, while current icons use `cd796c98565fc466923fc1128b962e133fa3c612`. See `assets/icons/LICENSE.md` for the upstream license. Names and logos remain trademarks of their respective owners; their inclusion does not imply endorsement, employment, certification, or affiliation. Logos illustrate the disciplines in the timeline rather than exhaustively documenting a production tool stack.

Animations use CSS inside SVG image assets, with a static base composition and a reduced-motion media query. Browser and GitHub image-proxy behavior may affect animation playback. No scripts or interactive controls are embedded inside the SVGs. In addition to the five chapter controls, there are 49 independent native GitHub details/summary controls, one for each technology occurrence in the journey. Each contains exactly one logo and opens its corresponding workflow, with separate contexts where Python and PostgreSQL recur in later chapters. Opening a section reveals a looping animation but does not guarantee restarting its timeline. The README contains no navigation links, contact buttons, or text-journey fallback. Everything stays inside the README; no external interactive page is published.

The diagrams are conceptual, simplified examples of technology roles. They are not live metrics, GitHub statistics, performance claims, complete reference architectures, or descriptions of proprietary model internals. The AI tool loops depict application orchestration. Dates and career areas follow the account owner's supplied timeline.

Reference concepts include [Kubernetes reconciliation](https://kubernetes.io/docs/concepts/architecture/controller/), [Kafka partition offsets](https://kafka.apache.org/39/implementation/distribution/), and [PyTorch autograd](https://docs.pytorch.org/docs/stable/notes/autograd.html).
